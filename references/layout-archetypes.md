# 패널 레이아웃 유형 (Pinterest 분류 기준 = 렌더러 프리셋)

판 전체를 12열(또는 3열) 그리드로 보고, 칸 크기의 위계로 구분한다.
`slot` 번호는 `panel.json`의 `cells[].slot` 값이다.

| 유형 (`layout.preset`) | 알아보는 법 | 슬롯 |
|---|---|---|
| `hero-strip` | 큰 대표 그림 1개(판의 40~55%) + 옆 세로 2칸 + 아래 가로 띠 3~4칸 | 0 제목 · 1 히어로(8×4) · 2,3 옆칸 · 4~7 아래 띠 |
| `bento` | 크기가 다른 사각 타일이 빈틈없이 맞물림, 강한 크기 대비 | 0 제목 · 1 큰칸(5×2) · 2 · 3 세로칸 · 4 · 5 · 6 넓은칸 · 7 |
| `storyboard-3x3` | 같은 크기 그림이 3×3 반복, 칸마다 짧은 설명 (단계·요소 분해) | 0 제목 · 1~9 |
| `timeline-band` | 가로로 긴 시간 띠가 위쪽을 가로지르고 그 아래 장(章)별 칸 | 0 제목 · 1 타임라인 · 2~4 큰칸 · 5~8 작은칸 |
| `editorial` | 왼쪽 좁은 글 단 + 가운데 큰 그림 + 오른쪽 작은 칸 세로 | 0 제목 · 1 글 · 2 히어로 · 3~5 오른쪽 · 6~8 아래 |
| `exploded-center` | 가운데 분해 액소가 세로로 길게, 양옆에 분석 다이어그램 3개씩 | 0 제목 · 1~3 왼쪽 · 4 가운데 히어로 · 5~7 오른쪽 |
| `render-band` | 세로 판. 맨 위 전체 폭 렌더 띠(판 높이의 30~35%), 가운데 다이어그램 격자, 맨 아래 렌더 2장 + 작은 칸 | 0 제목 · 1 범례 · 2 메인 렌더 · 3~5 한 줄 3칸 · 6 큰 다이어그램(7×2) · 7,8 오른쪽 · 9,10 아래 렌더 · 11 |
| (프리셋 없음) 펼침면 지도+격자 | 두 쪽 펼침. 왼쪽은 판 전체에 연한 바탕 지도(건물 바닥 모양·등고선) + 십자 격자, 격자 칸에 연표 카드. 오른쪽은 위아래 사진 띠, 가운데 [원래 모습 > 추출 아이소 + 글] 3줄과 "+", "=" 결과 렌더 | `background` + `crossGrid` + `card`/`glyph` (spec.md) |
| `other` | 위에 없는 구성 → `grid`로 직접 나눈다 | — |

## 프리셋에 없는 구성 옮기기
레퍼런스 스크린샷 위에서 세로선·가로선이 정렬되는 위치를 찾아 열 수와 행 높이 비율을 정한다.
```json
"grid": { "columns": 12, "rowHeights": [0.4, 1, 1, 0.8], "gutter": 24 },
"cells": [ { "id": "hero", "col": 0, "row": 1, "colSpan": 7, "rowSpan": 2, "type": "exploded", "data": {} } ]
```
- `rowHeights`는 비율(합이 1일 필요 없음). 제목 띠는 0.3~0.6.
- 여백 `page.margin`, 칸 사이 `grid.gutter`(pt). 기본값은 판 짧은 변의 3.5% / 1.4%.
- 프리셋을 쓰면서 `grid`의 일부(예: `gutter`, `rowHeights`)만 덮어쓸 수도 있다.

## 2024~2026 보드에서 자주 보이는 표현 (조사 때 확인할 것)
- 흰 바탕 + 검은 선 + 강조색 1~2개 (빨강/주황 계열, 황토/올리브)
- 맥락은 연회색 유령선, 주제만 진하게
- 같은 시점의 작은 그림을 반복해 단계·요소를 설명 (small multiples)
- 번호(01, 02 …)와 굵은 소제목, 아주 작은 설명 글
- 두꺼운 L자 모서리 표시, 얇은 칸 구분선
실제 판정은 그때그때 검색 결과로 한다. 이 목록은 분류를 돕는 힌트일 뿐이다.
